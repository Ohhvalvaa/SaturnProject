# SaturnProject palette

Black, grey and white. Elegance = few tones, lots of space, thin text, no bright colors.
The only "color" is light: pure white only for numbers and important states.

| Token | Value | Use |
|---|---|---|
| `deep-black` | `#000000` | Background behind the game, splash |
| `black` | `#0A0A0A` | Panel background |
| `graphite` | `#141414` | Cards and boxes inside the panel |
| `dark-grey` | `#262626` | Thin borders (1 px), separators |
| `grey` | `#5C5C5C` | Secondary text, labels, units |
| `light-grey` | `#9A9A9A` | Normal text, icons |
| `silver` | `#C8C8C8` | Values, bars and graphs |
| `white` | `#F5F5F5` | Main numbers (e.g. **120.0** FPS), highlighted text |
| `pure-white` | `#FFFFFF` | Only the controller symbols and the "active" state |

States are always greyscale, never red or green.

Typography: Segoe UI Variable (Display for big numbers, Text for the rest), Light/Regular/Semibold weights.
Corners 12 px, no shadows, 1 px `dark-grey` borders.

Logo: `saturn-logo.png` (transparent), `saturn-logo-on-black.png`, `saturn-logo-on-white.png`, `SaturnProject.ico`,
generated by `branding/logo.py` (Pillow).
